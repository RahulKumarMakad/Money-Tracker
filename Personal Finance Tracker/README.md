# Personal Financs Tracker

Personal Financs Tracker is a Flutter app for managing personal finances. It provides offline-first expense tracking, budgeting, and spending insights.

## Features

- Track expenses and manage budgets
- Review spending with analytics and charts
- Store data locally for offline use
- Export and share data as CSV

## Getting Started

Make sure you have the [Flutter SDK](https://docs.flutter.dev/get-started/install) installed.

From the project directory, run:

```sh
flutter pub get
flutter run
```
